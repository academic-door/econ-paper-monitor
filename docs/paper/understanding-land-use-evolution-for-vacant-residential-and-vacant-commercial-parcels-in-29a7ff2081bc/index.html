理解佛罗里达州迈阿密市闲置住宅与闲置商业地块的土地利用演变

Understanding land use evolution for vacant residential and vacant commercial parcels in Miami, Florida

Lauren Hoover, Sudipta Dey Tirtha, Naveen Eluru

摘要

In this study, we develop quantitative models to identify land use changes to individual parcels in Miami, FL. We focus on indicators for changes in population and economic activity. In our analysis, we identify the factors that promote this activity by examining how residential and commercial parcels are changing over time. While significant efforts have been conducted in earlier literature, there is limited work on understanding how parcels of a particular land use type change over time. The main aim of the proposed research effort is to contribute to land use evolution models that are customized by land use type. These frameworks can allow for quantitative exploration mechanisms for policy makers to proactively encourage sustainable adaptation due to emerging challenges associated with global climate change. The frameworks were developed using high-resolution parcel level data from the Florida Department of Revenue for the time period 2011–2020. The framework has two components: (1) a binary logit model to analyze what factors affect a change from the current land use designation and (2) for parcels selected for a change, a multinomial logit model, to examine the factors contributing to the new land use type. We built a joint model system that allows for a simultaneous estimation of the two decision processes. The joint model was estimated using a comprehensive set of independent variables including socio-demographic variables, economic development variables, and transportation infrastructure variables. The models developed were validated using hold-out sample data to show the value of the proposed model system

中文摘要

在本研究中，我们开发了定量模型，以识别佛罗里达州迈阿密市个别地块的土地利用变化。我们重点关注人口和经济活动变化的指标。在分析中，我们通过考察住宅和商业地块随时间的变化，识别促进这种活动的因素。尽管早期文献中已有大量研究，但针对特定土地利用类型地块随时间变化的理解工作仍然有限。本研究的主要目标是贡献于按土地利用类型定制的土地利用演化模型。这些框架能够为政策制定者提供定量探索机制，以主动鼓励因全球气候变化带来的新兴挑战而进行的可持续适应。这些框架是利用佛罗里达州税务局2011年至2020年间的高分辨率地块级数据开发的。该框架包含两个组成部分：（1）一个二元Logit模型，用于分析哪些因素影响当前土地利用指定状态的变化；（2）对于被选中发生变化的土地地块，一个多项Logit模型，用于考察促成新土地利用类型的因素。我们构建了一个联合模型系统，允许对两个决策过程进行同时估计。该联合模型使用了一组全面的自变量进行估计，包括社会人口变量、经济发展变量和交通基础设施变量。所开发的模型通过保留样本数据进行了验证，以展示所提出的模型系统的价值。
